## 0. สิ่งที่บทความรายงาน (จากบทคัดย่อ)

- ดักจับ CO₂ จากโรงไฟฟ้าแม่เมาะ หน่วยแบบ ultra-supercritical (USC) ขนาด **655 MW** แล้วนำไปผลิต **เมทานอล** และ **กรดฟอร์มิก**
- ใช้ **LCA + การวิเคราะห์ต้นทุน** เทียบกับการกักเก็บ CO₂ ใต้ดิน (CCS) และการผลิตกรดฟอร์มิกแบบเดิม
- กรดฟอร์มิกจาก CO₂ ได้คะแนนผลกระทบต่ำกว่าแบบเดิมใน **16–17 จาก 18 หมวด** ยกเว้นบางหมวด เช่น การใช้น้ำ (water depletion), ความเป็นพิษต่อระบบนิเวศบนบก และการทำลายโอโซน
- เทียบกับ CCS: ลดก๊าซเรือนกระจกได้ราว **721,000 t CO₂e/ปี** และราว **1,465,000 t CO₂e/ปี** ในกรณีมองโลกในแง่ดี

## 1. ต้นทุนต่อตัน CO₂ ที่ดักจับ

**วิธีคำนวณ**

```
ต้นทุน (USD/t) = [CAPEX × CRF + Fixed O&M + (ค่าพลังงาน + ค่าสารเคมี) × ปริมาณ CO₂ ที่ดักจับ] ÷ ปริมาณ CO₂ ที่ดักจับ
CRF = r(1+r)^n / ((1+r)^n − 1)
```

| สมมติฐาน | ค่า |
|---|---|
| กำลังผลิต / capacity factor | 655 MW / 80 % |
| ค่าการปล่อย (ลิกไนต์ USC) | 0.95 t CO₂/MWh |
| อัตราการดักจับ (MEA 30 wt%) | 90 % |
| CAPEX ระบบดักจับและอัด | 900 ล้าน USD |
| อัตราคิดลด / อายุโครงการ | 8 % / 25 ปี (CRF = 0.0937) |
| Fixed O&M | 3 % ของ CAPEX ต่อปี |
| energy penalty (ไอน้ำ reboiler ≈ 3.6 GJ/t + การอัด) | 0.28 MWh/t CO₂ × 60 USD/MWh |
| MEA ที่ต้องเติมเพิ่ม | 1.5 kg/t × 2 USD/kg |
| อัตราแลกเปลี่ยน | 34 บาท/USD |

**ผลการคำนวณ**

| รายการ | ค่า |
|---|---|
| ไฟฟ้าที่ผลิต | 4.59 TWh/ปี |
| CO₂ ที่ปล่อย | 4.36 ล้านตัน/ปี |
| CO₂ ที่ดักจับ | **3.92 ล้านตัน/ปี** |
| – CAPEX | 21.5 USD/t |
| – Fixed O&M | 6.9 USD/t |
| – พลังงาน + สารเคมี | 21.8 USD/t |
| **ต้นทุนดักจับ** | **≈ 50 USD/t CO₂ ≈ 1,700 บาท/t** |

**ความไว (sensitivity):** CAPEX 600–1,200 ล้าน USD → 41–60 USD/t; ราคาไฟฟ้า 40–90 USD/MWh → 45–59 USD/t;
capacity factor 60–90 % → 60–47 USD/t ดังนั้นช่วงที่สมเหตุสมผลคือ **ประมาณ 40–60 USD/t (1,400–2,000 บาท/t)**
ซึ่งสอดคล้องกับค่าทั่วไปของการดักจับหลังการเผาไหม้ด้วย MEA ในโรงไฟฟ้าถ่านหิน
ถ้ารวมค่าขนส่งและกักเก็บ (CCS) จะเพิ่มอีกราว 10–20 USD/t

**ต้นทุนกรดฟอร์มิกโดยประมาณ** (CO₂ + H₂ → HCOOH, ต่อ 1 ตัน HCOOH 100 %)

| รายการ | ปริมาณ | USD/t |
|---|---|---|
| CO₂ | 0.956 t | 48 |
| H₂ (ไฮโดรเจนสีเขียว 4 USD/kg) | 43.8 kg | 175 |
| ไอน้ำ (แยก formate + กลั่น) | 15 GJ | 120 |
| ไฟฟ้า | 0.3 MWh | 18 |
| CAPEX (1,200 USD ต่อกำลังผลิต 1 t/ปี) | – | 112 |
| อื่น ๆ (ตัวเร่งปฏิกิริยา เอมีน แรงงาน) | – | 40 |
| **รวม** | | **≈ 510 USD/t (≈ 17,500 บาท/t)** |

ถ้าใช้ไฮโดรเจนสีเทา (1.8 USD/kg) ต้นทุนเหลือ ≈ 420 USD/t แต่ประโยชน์ด้านสิ่งแวดล้อมจะลดลงมาก
**ต้นทุนหลักคือ H₂ และไอน้ำ ไม่ใช่ CO₂**

**ข้อจำกัดสำคัญ:** ถ้านำ CO₂ ทั้ง 3.9 ล้านตัน/ปีไปผลิตกรดฟอร์มิก จะได้ ~4.1 ล้านตัน/ปี
ซึ่งมากกว่าตลาดโลกทั้งหมด (~1 ล้านตัน/ปี) หลายเท่า ในทางปฏิบัติจึงใช้ได้เพียง
**slipstream** (ส่วนแบ่งเล็ก ๆ) ของ CO₂ ที่ดักจับได้ ส่วนที่เหลือต้องทำ CCS หรือผลิตเมทานอล

## 2. กระบวนการ (บทความนี้เป็นการศึกษาเชิงแบบจำลอง)

บทความนี้ **ไม่ใช่การทดลองในห้องปฏิบัติการ** แต่เป็นการประเมินด้วยแบบจำลองกระบวนการ + LCA ตามแนวทางทั่วไปดังนี้

1. **นิยามเป้าหมายและขอบเขต (ISO 14040/14044):** หน่วยหน้าที่ (functional unit) เช่น 1 ตันผลิตภัณฑ์ หรือ CO₂ ต่อปี;
   ขอบเขตแบบ cradle-to-gate: เหมืองลิกไนต์ → โรงไฟฟ้า → การดักจับ → การผลิตสารเคมี
2. **กำหนดสถานการณ์เปรียบเทียบ:** (ก) ไม่ดักจับ (ข) CCS (ค) CCU-เมทานอล (ง) CCU-กรดฟอร์มิก เทียบกับการผลิตแบบเดิม
3. **บัญชีรายการ (inventory):** สมดุลมวลและพลังงานจากแบบจำลองกระบวนการ (เช่น Aspen Plus) และฐานข้อมูล (เช่น ecoinvent, ข้อมูลไทย)
4. **ประเมินผลกระทบ:** 18 หมวด midpoint (ตรงกับวิธี ReCiPe) เช่น ภาวะโลกร้อน, การใช้น้ำ, ความเป็นพิษ
5. **วิเคราะห์ต้นทุน:** CAPEX/OPEX, ต้นทุนต่อหน่วย, วิเคราะห์ความไวและกรณีมองโลกในแง่ดี

**ขั้นตอนกระบวนการที่ถูกจำลอง**

```
ก๊าซไอเสีย (CO₂ ~12–14 %)
 → FGD/ล้างก๊าซ (SO₂ < 10 ppm เพื่อไม่ให้ MEA เสื่อม)
 → หอดูดซับ (absorber) ด้วย MEA 30 wt%, 40–60 °C
 → หอไล่ก๊าซ (stripper) 110–120 °C, reboiler ≈ 3.5–4 GJ/t CO₂
 → CO₂ บริสุทธิ์ > 99 % → อัด / ทำให้แห้ง
 → ไฮโดรจิเนชัน: CO₂ + H₂ + เอมีนตติยภูมิ (เช่น ไตรเอทิลเอมีน) บนตัวเร่งปฏิกิริยา Ru/Ir, 50–100 °C, 40–120 bar
 → ได้ formate–amine adduct → แตกตัวด้วยความร้อน + กลั่น → HCOOH 85–99 %; เอมีนวนกลับมาใช้ใหม่
```

(อีกเส้นทางหนึ่งคือการรีดักชันด้วยไฟฟ้า (electrochemical CO₂ reduction) ซึ่งยังอยู่ในระดับ TRL ต่ำกว่า)

**ถ้าต้องการทดลองจริงในห้องปฏิบัติการ (ข้อเสนอ)**

| ขั้นตอน | วิธีการ | วัดผล |
|---|---|---|
| 1. ดูดซับ CO₂ | ผ่านก๊าซผสม 13 % CO₂/N₂ เข้า MEA 30 wt% ในคอลัมน์แบบฟอง (bubble column) ที่ 40 °C | CO₂ loading (mol CO₂/mol MEA) ด้วยการไทเทรต, gas analyzer ที่ขาออก |
| 2. ไล่ CO₂ | ให้ความร้อนสารละลายที่ 110–120 °C | ปริมาณ CO₂ ที่ปล่อย, ความร้อนที่ใช้ (GJ/t) |
| 3. ไฮโดรจิเนชัน | autoclave ที่มีตัวเร่งปฏิกิริยา + base, H₂/CO₂ 1:1, 40–80 bar | TON/TOF, ผลได้ของ formate |
| 4. แยกและทำให้บริสุทธิ์ | แตกตัว adduct, กลั่นภายใต้สุญญากาศ | ความบริสุทธิ์ของผลิตภัณฑ์ |
| 5. วิเคราะห์คุณภาพ | HPLC/IC หรือ ¹H-NMR, การไทเทรตกรด-ด่าง, Karl Fischer (น้ำ), ICP-MS (โลหะ), APHA (สี) | เทียบกับเกณฑ์ในหัวข้อ 3 |

## 3. คุณภาพของกรดฟอร์มิก

**เกรดอุตสาหกรรมทั่วไป:** 85 %, 90 %, 94 %, 98–99 % (w/w) ส่วนที่เหลือเป็นน้ำเกือบทั้งหมด

| พารามิเตอร์ | เกณฑ์ทั่วไปของเกรดอุตสาหกรรม (ประมาณ) |
|---|---|
| ความเข้มข้น HCOOH | ≥ 85 / 90 / 94 / 98 % |
| สี (Hazen/APHA) | ≤ 10–20 |
| กรดอะซิติก | ≤ 0.4 % |
| คลอไรด์ (Cl⁻) | ≤ 0.002–0.005 % |
| ซัลเฟต (SO₄²⁻) | ≤ 0.001–0.002 % |
| เหล็ก (Fe) | ≤ 0.0005 % |
| โลหะหนัก (Pb) | ≤ 0.0005 % |
| สารตกค้างหลังระเหย | ≤ 0.006–0.02 % |

(ช่วงค่าข้างต้นเป็นค่าทั่วไปจากมาตรฐานเกรดอุตสาหกรรม เช่น GB/T 2093 และข้อกำหนดของผู้ผลิต
ต้องตรวจสอบกับมาตรฐานหรือสเปกของผู้ซื้อที่ใช้จริง)

**สิ่งปนเปื้อนที่ต้องเฝ้าระวังเป็นพิเศษในกรดฟอร์มิกจาก CO₂**

- **เอมีนตกค้าง** (ไตรเอทิลเอมีน หรือ MEA / nitrosamine ที่ติดมาจากขั้นดักจับ) — ต้องต่ำระดับ ppm สำหรับงานอาหารสัตว์/ยา
- **โลหะจากตัวเร่งปฏิกิริยา** (Ru, Ir) — ต้องต่ำระดับ ppb–ppm
- **SOx, NOx, O₂, ปรอท และเถ้า** จากไอเสียถ่านหิน — ทำให้ตัวเร่งปฏิกิริยาเสื่อมและปนเปื้อนผลิตภัณฑ์
  โดยควรใช้ CO₂ ที่บริสุทธิ์ > 99.9 % และ SO₂ / O₂ อยู่ในระดับไม่กี่ ppm ก่อนเข้าขั้นไฮโดรจิเนชัน
- **น้ำ** — HCOOH กับน้ำเกิด azeotrope (~77 % ที่ 1 atm) การทำให้เข้มข้นเกิน 85 % จึงต้องใช้พลังงานสูงหรือ pressure-swing distillation

**สรุป:** หากกลั่นจนได้ ≥ 85 % และผ่านเกณฑ์สิ่งปนเปื้อนข้างต้น กรดฟอร์มิกจาก CO₂ ใช้แทนเกรดปกติได้
(เป็นโมเลกุลเดียวกัน) เพียงแต่ต้องพิสูจน์ด้วยผลวิเคราะห์ (CoA) ว่าไม่มีเอมีนและโลหะตกค้าง

## 4. นำไปใช้ในกระบวนการใดในโรงงาน

**ในประเทศไทย (ตลาดหลัก)**

| อุตสาหกรรม | กระบวนการ | เกรดที่ใช้ |
|---|---|---|
| **ยางพารา** (ใช้มากที่สุดในไทย) | ทำให้น้ำยางจับตัว (coagulation) ในการผลิตยางแผ่นรมควัน, ยางแท่ง STR, ยางเครป | 85–94 % เจือจางเหลือ ~1–2 % |
| ฟอกหนัง | ขั้น pickling และ fixing สีย้อม/โครเมียม | 85 % |
| สิ่งทอ | ปรับ pH อ่างย้อม, ตรึงสีย้อมกรด (nylon/ขนสัตว์) | 85 % |
| อาหารสัตว์ / หญ้าหมัก | สารกันเสีย, ลดเชื้อ Salmonella, สารเติมแต่งในอาหารหมูและไก่ | 85 % (เกรดอาหารสัตว์) |
| ปศุสัตว์และผึ้ง | ฆ่าเชื้อ, กำจัดไร Varroa | 60–85 % |
| เคมีภัณฑ์ / ยา | สารตั้งต้นสำหรับ formate ester, formamide, ยาและสารกำจัดศัตรูพืช | 98–99 % |
| ปิโตรเลียม | น้ำเกลือ formate สำหรับเจาะหลุม (K/Cs formate) | – |
| พลังงาน | ตัวเก็บ H₂ (hydrogen carrier), เชื้อเพลิงสำหรับ fuel cell (DFAFC) | ≥ 98 % |

**ภายในโรงไฟฟ้าถ่านหินเอง (ใช้กรดที่ผลิตได้ภายในโรงงาน)**

- **ระบบกำจัด SO₂ แบบเปียก (wet limestone FGD):** เติมกรดฟอร์มิก/formate เป็น buffer เพื่อเพิ่มประสิทธิภาพการดูดซับ SO₂ (คล้ายการใช้กรดอะดิพิก)
- **ล้างหม้อไอน้ำด้วยสารเคมี (boiler chemical cleaning):** สูตร hydroxyacetic–formic acid ใช้ล้างตะกรันในหม้อไอน้ำ supercritical/USC แบบ once-through เพราะไม่มีคลอไรด์และสลายตัวได้เมื่อได้รับความร้อน
- **ปรับ pH / ทำความสะอาดระบบน้ำหล่อเย็นและถังเก็บ**

ปริมาณที่ใช้ภายในโรงไฟฟ้ามีน้อยมากเมื่อเทียบกับ CO₂ ที่ดักจับได้ จึงควรส่งขายให้อุตสาหกรรมยางและฟอกหนังเป็นหลัก

## 6. ต้นแบบระดับห้องปฏิบัติการและแผงควบคุมสาธิต

โครงการปรับเป้าแหล่ง CO₂ เป็น **โรงไฟฟ้าบางปะกง (กฟผ.)** และตลาดในเขต EEC ดูบริบททั้งหมดใน [`CLAUDE.md`](CLAUDE.md)

**การคำนวณ autoclave 100 ml** (`python3 lab_scale_calc.py`) กรณีอ้างอิง: ของเหลว 40 ml, อัด CO₂ 0.6 MPa + H₂ 1.2 MPa ที่ 25 °C, ทำปฏิกิริยาที่ 80 °C 2 ชม.

| รายการ | ค่า |
|---|---|
| CO₂ / H₂ ที่อัดเข้า | 14.52 / 29.05 mmol (H₂:CO₂ = 2) → **CO₂ เป็นสารกำหนดปริมาณ** |
| กรดฟอร์มิกตามทฤษฎี | 0.668 g |
| กรดฟอร์มิกจริง (conversion 30 %, selectivity 90 %) | **0.180 g** (ผลได้ 27 %, 4.5 g/L) |
| ความดันที่ 80 °C | 2.13 MPa (71 % ของขีดจำกัด liner 3 MPa) |
| PEM electrolyzer ผลิต H₂ ที่ 2 A | 5,900 C, ≈ 49 นาที, ≈ 3.1 Wh |

conversion และ selectivity เป็นค่าสมมติ ต้องแทนด้วยผลวัดจริง และจำนวนโมลคิดเฉพาะก๊าซในช่องว่างเหนือของเหลว (ไม่รวม CO₂ ที่ละลาย)

**แผงควบคุม ESP32** ([`esp32_demo/`](esp32_demo/)) จำลองการทำงานทั้งรอบ: อัดก๊าซ → ให้ความร้อน → ทำปฏิกิริยา → ทำให้เย็น
แสดงอุณหภูมิ ความดัน อัตราการไหล และผลได้บนจอ OLED พร้อมป้าย **SIM** (ค่าทั้งหมดเป็นการจำลอง)

- ต่อสาย: OLED SDA→GPIO21, SCL→GPIO22; ปุ่ม START→GPIO25, PAGE→GPIO26, TEMP→GPIO27 (ต่อลง GND); LED เตือน GPIO2
- ไลบรารี: Adafruit SSD1306 + Adafruit GFX; เวลาเร่ง 120 เท่า (รอบ 4 ชม. ใช้ ≈ 2 นาที)
- กด START = เริ่ม/ยกเลิก, PAGE = เปลี่ยนหน้าจอ, TEMP = setpoint 60/80/100/120 °C
- **สาธิตระบบความปลอดภัย:** กด PAGE ค้างไว้แล้วกด START → อัดก๊าซ 2 เท่า ความดันขึ้นจนเตือน HIGH และวาล์วระบายความดันเปิด
- Serial 115200 ส่งข้อมูล CSV สำหรับพล็อตกราฟ
- ทดสอบแบบจำลองบนคอมพิวเตอร์: `cd esp32_demo && g++ -std=c++11 -o sim_test sim_test.cpp && ./sim_test`
